## 👋 &nbsp;About Me

I'm a **MERN stack developer** who enjoys owning a product end to end: modeling the data in MongoDB, building secure APIs with Node.js and Express, crafting the UI in React / Next.js, and shipping it with a clean deployment pipeline.

> *Design it clean. Build it full-stack. Deploy it right.*

| | |
|---|---|
| 🚀 **Building** | End-to-end MERN apps, from schema to deployed UI |
| 🔐 **Working with** | JWT auth, role-based access and Socket.io real-time features |
| ☁️ **Deploying** | Dockerized apps on Vercel, Netlify and AWS with CI pipelines |
| 🧪 **Testing** | API contracts with Postman / Insomnia, unit tests with Jest |
| 🤝 **Open to** | Full-time roles · Freelance projects · Collaboration |
